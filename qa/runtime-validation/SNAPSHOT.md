# 平台运行时验证快照

2026-10-14 保存的独立小型运行时验证源码与测试，用于保留平台适配决策的证据，不是第四款游戏，也不是装箱游戏的实际运行入口。

此快照来自完成的 runtime-spike 验证任务。没有复制临时目录、浏览器资料、密钥或生成 dist；`SHA256SUMS.txt` 列出复制时各文件摘要。保留原文档的验证范围与未验证结论。

这里的适配器是当时的验证样本；装箱游戏使用根目录 `platforms/` 的版本，其中另有后续 BFCache 生命周期修复，不应以本快照覆盖游戏适配器。

单独执行验证：在游戏根目录运行 `npm run test:runtime-proof`。游戏自身的 `npm test` 只运行根 `test/` 中的测试，二者统计分开。

真实抖音开发者工具、AppID、平台上传、官方编译器与真机测试仍未完成。
