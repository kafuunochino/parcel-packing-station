# 快递收纳站 · 50关封签工位 Demo

0.3.0，2026-10-14。单机中文 Canvas2D 装箱解谜。先旋转、挪动和压缩软包，再决定给后批留下什么形状的空位。所有游戏、菜单、货单、教程、工具与结算均在画布内，HTML 只有全屏宿主。

## 这一版的玩法

- **1–5关入门**：选择放置、旋转、形状借位、固定隔板、软包压缩/展开。第一箱只需两次放置。
- **6–10关正常体验**：保留原有10关全部几何、参考解、撤回、重装、存档和音效。
- **11–20关早班接货**：两批装箱，货单从一开始就显示全部货物轮廓。主动封签后，本批位置锁定。
- **21–30关雨天隔板**：隔板和软包改变给第二批预留的形状。
- **31–40关夜班接力**：三批交接；**41–50关最后一车**：四批组合。最大棋盘仍为6×6，不靠缩小触点增加难度。
- 50关都是冻结的具体设计，不在运行时随机生成。每关都有逐批封签参考解，并通过独立精确覆盖求解器验证初始可解。
- 11–50关各有一个合法的错误封签见证：空位数量看似足够，但留下的形状无法装下后批。只有确认无解才进入清楚的失败页；求解预算不足不会被当成失败。
- 失败来自玩家先前的封签选择，不投放初始无解关，不暗改包裹、不藏后续轮廓、不倒计时、不扣体力。免费重开始终可用。

## 金币、有限道具、广告预留

每关首次通关获得20金币，再刷本关不重复发放。金币没有充值或现实货币价值，只能用于以下功能：

| 功能 | 金币 | 作用 | 每次开局限制 |
| --- | ---: | --- | --- |
| 封签预检 | 6 | 检查当前摆法封签后是否仍有解，不自动摆放 | 1次 |
| 定位贴 | 8 | 标出一件当前包裹的位置和方向，不直接过关 | 1次 |
| 拆签复活 | 10 | 失败后回到最后一次封签前，保留已摆位置供调整 | 1次 |

不适用、检查未完成或金币不足时不扣钱、不消耗次数。每箱重开免费，参考拼法也保留为免费学习入口。

浏览器 Demo 提供**明确标注的开发用模拟广告**，必须人工选择模拟完成、提前关闭、无填充或错误之一，不自动成功、不播放真实广告、不联网。只有完成且请求、开局、关卡、批次/失败状态都匹配时才发一次可用奖励。取消、异常、超时、换关、重开和旧回调不奖励。抖音候选广告能力默认 disabled，没有真实广告单元、SDK广告调用、广告账户或变现配置。

## 视觉、剧情和手机操作

- 深绿仓库、牛皮纸纸箱、运单夹、完整货单和五章交接小故事，由同事阿乔做轻量引导。
- 原创代码绘制箱体折面/纸纹、软包缝线、整体包裹轮廓、封签胶带、投影/条码和9类物品图记（茶叶、香氛、陶杯、饼干、棉袜、木玩、旅行、文具、围巾）；放置/挤压弹动、盖章、拆签和出库纸屑反馈。没有购买素材或运行时AI。
- 手机按实际CSS像素布局，不缩放旧桌面界面。320×568及覆盖的安全区内，按钮、包裹卡、棋盘格均至少44px。常规高度最多三件一页货架，五章分页选关。极端安全区（320×568，顶部92/底部34）使用可开关的游戏内货架面板，棋盘与按钮仍>=44px，不把竖屏挡在旋转提示页。
- 桌面为居中工位；过短横屏提示竖起设备并保留状态。安全区偏移同时用于绘图和输入。
- 点击与拖放均可；第二触点不劫持手势，取消拖放不改变摆放，弹层立即失效旧命中区。

## 运行和证据

Node.js20+，核心运行与测试无需第三方依赖。

```sh
npm test
npm run verify
npm run build
npm start
```

- `npm test`：302项自动化通过，含50关×9视口真实游戏入口指针流程、软包、保存迁移、40个错误封签、复活、金币和奖励幂等。
- `npm run verify`：50个初始解与完整逐批参考解、40个错误封签及复活验证。
- `npm run build`：生成 `dist/parcel-demo.html` 自包含离线试玩和 `dist/douyin/` 候选，以及逐文件 SHA256 清单。不联网、不上传。
- `node qa/campaign-native-check.mjs`：可选QA工具，需已安装 `@napi-rs/canvas` 和真实Noto CJK字体。执行精确HTML里的浏览器适配器，检查真实原生Canvas像素和50关指针流程。**不是浏览器截图、手机或官方工具验证**。
- 证据在 `artifacts/campaign-test-output.txt`、`campaign-verification.json`、`campaign-reference-output.txt`、`native-campaign/REPORT.json`；旧0.1/0.2的CLI与测试证据仅作历史记录，不能证明本版已平台通过。
- 可只读检查 `window.__parcelGame.getSnapshot()`；返回深拷贝，不提供动作注入。
